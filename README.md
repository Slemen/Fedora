# Настройка Fedora KDE для Acer Nitro V15-51 (v51)

Набор автоматизированных скриптов для быстрой и чистой настройки **Fedora KDE** на игровом ноутбуке **Acer Nitro V15-51**.

> **Дисклеймер:** Скрипты созданы исключительно для личных нужд и конкретного оборудования (**Acer Nitro V15-51**). Автор не несёт ответственности за последствия их использования на других конфигурациях.

---

## Быстрый запуск на чистой системе

Перед запуском убедитесь, что в **BIOS выключен Secure Boot** (необходимо для загрузки проприетарных модулей ядра `nvidia` и `linuwu_sense`).

**Основная короткая команда:**
```bash
curl -fsSL slemen.github.io/Fedora/go -o /tmp/go && bash /tmp/go
```

**Резервная прямая команда с GitHub:**
```bash
curl -fsSL https://raw.githubusercontent.com/Slemen/Fedora/main/install.sh -o /tmp/install.sh && bash /tmp/install.sh
```

## Состав этапов установки

1. **`01_base_and_nvidia.sh` — База, драйвер NVIDIA и ядро:**
   * Настройка DNF5 (`max_parallel_downloads=10`, `fastestmirror=True`, `defaultyes=True`, `timeout=30`, `ip_resolve=4`).
   * Подключение репозиториев **RPM Fusion (Free и Nonfree)** и полное обновление системы.
   * Установка **Timeshift**, проприетарного драйвера **NVIDIA**, CUDA и инструментов сборки ядра.
   * Применение ядерных твиков `sysctl` (NVMe, ZRAM, `vm.max_map_count`, `fs.file-max`, сетевой стек **TCP BBR**) и надёжная блокировка таймера `iTCO_wdt`.
2. **`02_software_and_env.sh` — Софт, игровое окружение и терминал:**
   * Установка мультимедиа-кодеков (`ffmpeg`, `gstreamer1-*`, `lame`).
   * Установка **Steam** и системных утилит (`system76-scheduler`, `earlyoom`, `fish`, `starship`, `fastfetch`, `btop`, `nano`).
   * Настройка буфера звука PipeWire (`1024`), переменных Wayland и оптимизированного враппера **`nvgame`** (дискретная NVIDIA, системный `gamemoderun`, кэш шейдеров на NVMe объёмом **10 ГБ** без автоочистки, блокировка лишних неявных слоёв Vulkan `VK_LOADER_LAYERS_DISABLE="~implicit~"`).
   * Настройка оболочки **Fish** (алиасы `gpuinfo`, `upd`, `clean` и встроенный русский индикатор времени выполнения команд в `fish_prompt`), темы Konsole **Newbl1nk** и редактора **Nano**.
3. **`03_install_damx.sh` — Управление охлаждением и питанием Acer:**
   * Установка модуля ядра `linuwu_sense` и **Div Acer Manager Max (DAMX)** из локальной папки (`~/Документы` / `~/Documents`) или напрямую с GitHub.
4. **`04_verify_setup.sh` — Диагностика:**
   * Автоматическая проверка всех **18 пунктов** конфигурации после завершения настройки.

## Рекомендуемый порядок действий

1. Запустите меню и выполните **Пункт 1** → дождитесь сборки модуля NVIDIA (2–3 мин) → выберите **Пункт 5 (Перезагрузка)**.
2. После перезагрузки откройте **Timeshift** и создайте первый базовый снимок системы (Btrfs).
3. Снова откройте меню, выполните **Пункт 2** → выберите **Пункт 5 (Перезагрузка)**.
4. Выполните **Пункт 3** (установка DAMX), затем **Пункт 4** (проверка 18/18 пунктов).
5. В настройках игры **World of Tanks Blitz** в Steam укажите параметр запуска: `nvgame %command%` и выберите **Proton Experimental**.
