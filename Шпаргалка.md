# Шпаргалка полезных команд для Fedora KDE (Acer Nitro V15-51)

## 1. Игры и Steam (NVIDIA + GameMode)

* **Запуск игры на дискретной NVIDIA с GameMode и кэшем шейдеров 10 ГБ (Параметры запуска в Steam):**
  ```text
  nvgame %command%
  ```
* **Проверка активности GameMode (выполнять при запущенной игре):**
  ```fish
  gamemoded -s
  ```
  *(Ожидаемый ответ: `gamemode is active`)*
* **Проверка загрузки видеокарты NVIDIA и списка запущенных игр:**
  ```fish
  gpuinfo
  ```
  *(Алиас для `nvidia-smi`)*
* **Проверка поддержки Vulkan и драйвера NVIDIA:**
  ```fish
  vulkaninfo --summary
  ```
* **Проверка OpenGL рендерера (встройка Intel vs дискретная NVIDIA):**
  ```fish
  glxinfo | grep "OpenGL renderer"
  __NV_PRIME_RENDER_OFFLOAD=1 __GLX_VENDOR_LIBRARY_NAME=nvidia glxinfo | grep "OpenGL renderer"
  ```
* **Проверка аппаратного декодирования видео (VA-API):**
  ```fish
  vainfo
  ```

## 2. Управление ноутбуком (Div Acer Manager Max — DAMX)

* **Запуск графического интерфейса управления кулерами и батареей:**
  ```fish
  DAMX
  ```
* **Проверка статуса фоновой службы DAMX и модуля ядра `linuwu_sense`:**
  ```fish
  systemctl status damx-daemon.service
  lsmod | grep linuwu_sense
  ```

---

## 3. Обслуживание системы и алиасы Fish

* **Полное обновление системы (DNF + репозитории):**
  ```fish
  upd
  ```
  *(Алиас для `sudo dnf upgrade -y --refresh`)*
* **Очистка неиспользуемых пакетов и кэша DNF:**
  ```fish
  clean
  ```
  *(Алиас для `sudo dnf autoremove -y && sudo dnf clean all`)*
* **Проверка упавших системных служб:**
  ```fish
  systemctl --failed
  ```
* **Создание и управление снимками системы Btrfs:**
  ```fish
  sudo timeshift-gtk
  sudo timeshift --list
  ```

---

## 4. Накопитель NVMe SSD и файловая система Btrfs

* **Проверка параметров монтирования разделов (должно быть `noatime,compress=zstd:1`):**
  ```fish
  findmnt -t btrfs -o TARGET,OPTIONS
  ```
* **Проверка планировщика ввода-вывода NVMe (должно быть `[none]`; при нескольких SSD проверьте также `nvme1n1` и т.д.):**
  ```fish
  cat /sys/block/nvme0n1/queue/scheduler
  ```
* **Ручной запуск очистки блоков SSD (TRIM):**
  ```fish
  sudo fstrim -av
  ```
* **Проверка занимаемого места системными логами `journald` (лимит 150 МБ):**
  ```fish
  journalctl --disk-usage
  ```

---

## 5. Сеть и ядерные оптимизации

* **Проверка сетевого планировщика CAKE и алгоритма BBR:**
  ```fish
  sysctl net.core.default_qdisc net.ipv4.tcp_congestion_control
  ```
* **Проверка работы драйвера синхронизации `ntsync` для Wine/Proton:**
  ```fish
  ls -la /dev/ntsync
  ```
* **Проверка сжатой оперативной памяти ZRAM:**
  ```fish
  zramctl
  ```

---

## 6. Работа с репозиторием GitHub (`Slemen/Fedora`)

* **Быстрый запуск меню установки на чистой системе:**
  ```bash
  curl -fsSL https://slemen.github.io/Fedora/go -o /tmp/go && bash /tmp/go
  ```
* **Отправка обновлений из локальной папки `~/Fedora` на GitHub:**
  ```fish
  cd ~/Fedora
  git status
  git add .
  git commit -m "Update scripts"
  git push origin main
  ```
