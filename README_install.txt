================================================================================
КОРОТКАЯ ПАМЯТКА ДЛЯ ЧИСТОЙ УСТАНОВКИ FEDORA KDE (ACER NITRO V 15)
================================================================================

1. УСТАНОВКА ЧИСТОЙ СИСТЕМЫ И ПЕРЕНОС ФАЙЛОВ
--------------------------------------------------------------------------------
- Разметка диска: Установите Fedora KDE Spin по пункту 1.3 чек-листа
  (разделы /boot/efi, /boot и независимые подтома @ и @home на одном уровне в Btrfs).
- Копирование файлов: Распакуйте архив Fedora_kde_nitro_setup.tar.gz в папку
  ~/Документы/Fedora_kde_nitro_setup (права на запуск +x уже сохранены внутри).
- Скачайте свежий архив DAMX-*.tar.xz со страницы релизов:
  https://github.com/PXDiv/Div-Acer-Manager-Max/releases
  в папку ~/Документы/"Div Acer Manager Max" (или прямо в ~/Документы/Fedora_kde_nitro_setup).


2. ЭТАП 1 — БАЗА, НОВОЕ ЯДРО И ДРАЙВЕР NVIDIA
--------------------------------------------------------------------------------
Откройте терминал, перейдите в папку со скриптами и запустите первый этап:

  cd ~/Документы/Fedora_kde_nitro_setup
  ./01_base_and_nvidia.sh

После завершения работы скрипта обязательно перезагрузите ноутбук:

  sudo reboot


3. ПЕРВЫЙ СНИМОК В TIMESHIFT И ЭТАП 2 — СОФТ, ИГРЫ, FISH И LF
--------------------------------------------------------------------------------
- Снимок базы: После перезагрузки откройте Timeshift, настройте под Btrfs
  (исключив /home) и создайте первый эталонный снимок чистой системы с драйвером NVIDIA.
- Установка софта: Откройте терминал и запустите второй этап:

  cd ~/Документы/Fedora_kde_nitro_setup
  ./02_software_and_env.sh

После завершения снова перезагрузите ноутбук:

  sudo reboot


4. ЭТАП 3 — САМОДИАГНОСТИКА И ФИНАЛЬНЫЙ БЭКАП
--------------------------------------------------------------------------------
- Проверка системы: Запустите скрипт диагностики, чтобы убедиться в работе
  видеокарты (профиль P8), кодеков, GameMode и оболочки Fish:

  cd ~/Документы/Fedora_kde_nitro_setup
  ./03_verify_setup.sh

- Финал: После перезагрузки (sudo reboot) нажмите клавишу Nitro (или откройте
  Div Acer Manager Max из меню), в Internals Manager выберите профиль Nitro V4,
  включите ограничение заряда батареи 80% и сохраните финальный снимок в Timeshift.
